## Getting Started

### First Launch
When you first open Colorado Peaks Explorer:
1. The app will load peak data from its database
2. Peak images will download (requires internet)
3. Data is cached for offline use
4. Subsequent launches work offline

### System Requirements
- iPhone or iPad running iOS 15.0 or later
- Internet connection (first launch only)
- Approximately 50MB of storage for cached data

## Searching & Filtering

### Search Functionality

**To Search:**
1. Tap the search bar at the top
2. Type any of the following:
   - Peak name (e.g., "Longs Peak")
   - Range name (e.g., "Sawatch")
   - Elevation (e.g., "14433")
3. Results update in real-time
4. Tap ✕ to clear search

**Search Examples:**
- `Elbert` → Finds Mount Elbert
- `14` → Finds all fourteeners
- `Front Range` → Finds all Front Range peaks
- `Class 1` → Finds easy hikes
- `Sawatch` → Finds Sawatch Range peaks

### Filtering by Category

**All Peaks** (Default)
- Shows every peak in the database
- Includes both Top 200 and Front Range
- Best for browsing all options

**Top 200**
- Colorado's highest peaks
- All 53 fourteeners (14,000+ ft)
- Highest thirteeners (13,000-14,000 ft)
- Ranked by elevation

**Front Range**
- Peaks visible from Denver
- Includes viewing information
- Direction and distance from Denver
- Popular peaks like Longs, Pikes, Mount Blue Sky

### Sorting Options

**By Elevation** (Default)
- Highest peaks first
- Great for peak baggers
- Fourteeners at the top

**By Name**
- Alphabetical A-Z
- Easy to find specific peaks
- Good for reference

**By Prominence**
- Most prominent peaks first
- Shows most visually striking peaks
- Useful for photography

### Combining Search, Filter, and Sort

You can combine all three:
1. Select "Front Range" category
2. Search for "Peak"
3. Sort by "Elevation"
→ Shows Front Range peaks with "Peak" in name, highest first

## Google Maps Integration

### Opening in Maps
1. Scroll to bottom of detail screen
2. Tap **"Open in Google Maps"** button
3. Google Maps (or Apple Maps) opens
4. Peak location is pinned

### What Opens:
- **If Google Maps installed**: Opens in Google Maps app
- **If not**: Opens in Safari with Google Maps web
- **Fallback**: Opens in Apple Maps

### In Google Maps:
- See satellite imagery of the peak
- View terrain and topography
- Get driving directions to trailhead
- Explore nearby features
- Save location for later

### Tips:
- Save peak locations to Google Maps lists
- Create custom maps of peaks you want to climb
- Use Street View for trailhead previews
- Check terrain before hiking

## Offline Usage

### How Offline Mode Works

**First Launch (Requires Internet)**
1. Peak data loads from app bundle
2. Images download from internet
3. Everything caches locally
4. Takes ~2-5 minutes depending on connection

**Subsequent Launches (No Internet Needed)**
1. Data loads from cache instantly
2. Images load from cache
3. All features work normally
4. No internet required

### What Works Offline:
✅ Browse all peaks
✅ Search and filter
✅ View peak details
✅ View cached images
✅ Read all information

### What Requires Internet:
❌ Opening Google Maps (maps app needs internet)
❌ Downloading new images (if cache cleared)
❌ Refreshing data (optional, every 30 days)

### Cache Management
- Cache refreshes automatically every 30 days (if online)
- Manual refresh: Tap ↻ button on home screen
- Cache persists until app is deleted
- Approximately 50MB of storage used

## FAQ

### General Questions

**Q: How many peaks are in the app?**
A: 72 peaks total - 58 from the Top 200 list and 14 Front Range peaks visible from Denver.

**Q: Is the app free?**
A: Check the App Store listing for current pricing.

**Q: Does it work on iPad?**
A: Yes! Optimized for all iOS devices running iOS 15.0+.

**Q: Can I use it without internet?**
A: Yes, after the first launch when data is cached.

### Data Questions

**Q: Where does the data come from?**
A: Multiple reliable sources including climb13ers.com, 14ers.com, USGS, and SummitPost.

**Q: How accurate are the elevations?**
A: Elevations are from USGS data, accurate to within a few feet.

**Q: When was the data last updated?**
A: Data is current as of the app version date. Cache refreshes every 30 days.

**Q: Can I submit new peaks or corrections?**
A: Contact the developer through the App Store or GitHub.

### Feature Questions

**Q: Can I track which peaks I've climbed?**
A: Not in the current version. This is a planned feature.

**Q: Can I add my own photos?**
A: Not currently. Photos are from public sources.

**Q: Does it show weather?**
A: Not in the current version. This is a potential future feature.

**Q: Can I share peaks with friends?**
A: Open in Google Maps, then share from there.

### Technical Questions

**Q: Why isn't Google Maps opening?**
A: Ensure you have Google Maps or Apple Maps installed. Check internet connection.

**Q: App says "No peaks found"?**
A: Try refreshing (↻ button) or reinstall the app.

**Q: Images not loading?**
A: Check internet connection on first launch. After caching, works offline.

**Q: How much storage does it use?**
A: Approximately 50MB with all images cached.

### Hiking Questions

**Q: What do Class ratings mean?**
- **Class 1**: Hiking trail, no hands needed
- **Class 2**: Off-trail, maybe some hands for balance
- **Class 3**: Scrambling, use hands frequently
- **Class 4**: Climbing, most people use rope

**Q: Which fourteeners are easiest?**
A: Search "Class 1" - Mount Bierstadt, Quandary Peak, and Grays Peak are popular beginner fourteeners.

**Q: Are Front Range peaks always visible from Denver?**
A: Visibility depends on weather, air quality, and viewing location. Best on clear days.

**Q: Should I climb a peak based on this app alone?**
A: No. Always check current conditions, trail reports, weather, and your abilities. This app is for informational purposes only.

## Safety Notice

⚠️ **Important Safety Information**

- This app provides information only, not route guidance
- Always check current weather and trail conditions
- Know your abilities and limitations
- Bring proper gear for high-altitude climbing
- Tell someone your plans before hiking
- Colorado weather changes rapidly
- Start early to avoid afternoon thunderstorms
- Altitude sickness is serious - acclimate properly
- Many peaks require technical skills
- Consider hiring a guide for difficult peaks

For current conditions and route information:
- 14ers.com
- AllTrails.com
- Mountain-Forecast.com
- Local ranger stations
